# Humanitarian Projects Manager Demo Recording Pack

Use these small Word files for a reliable, visually impressive demo recording.

## Files

- `01_New_Project_Intake/01_Coastal_Cash_Shelter_Recovery_Proposal_and_Schedule.docx`: create a new ECHO project; includes project metadata, budget, geography, risks, embedded template, and explicit reporting schedule.
- `01_New_Project_Intake/02_ECHO_Flash_Interim_Report_Template.docx`: upload as a funder template from the project Documents tab.
- `02_Project_Evidence_Update/01_Q1_Field_Update_PDM_and_Risk_Log.docx`: upload as progress evidence; updates beneficiaries, risks, monitoring, and delivery data.
- `02_Project_Evidence_Update/02_Distribution_Reconciliation_and_Financial_Tracker.docx`: upload as financial tracker; supports report generation and intentionally leaves a few items requiring human update.

## Best Recording Order

1. Start on the dashboard and show KPIs, charts, map, and filters.
2. Open `Clean Water for Recovery` or `Dignity Through Cash` to show an existing rich project.
3. Generate a report from the Reporting tab, review the document-like draft, point out required sections and human-update flags, then save it.
4. Return to the dashboard and click New project.
5. Upload `01_Coastal_Cash_Shelter_Recovery_Proposal_and_Schedule.docx` with hints: ECHO, Shelter & Cash Assistance, Mozambique.
6. On the new project page, show overview metrics, documents, templates, and the schedule extracted from the proposal.
7. Upload the ECHO template, then upload the Q1 update and financial tracker as project evidence.
8. Refresh reporting schedule from docs if needed.
9. Generate the quarterly donor progress report, add a short prompt, regenerate, then save and show the schedule download link.
